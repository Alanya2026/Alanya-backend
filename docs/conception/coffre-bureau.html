Le coffre-fort sur ordinateur

Une petite application pour Windows et Linux qui ouvre le coffre-fort de l'inscrit sur son ordinateur : parcourir et regarder ses fichiers, en ajouter par glisser-déposer, les télécharger, les ranger, et sauvegarder un dossier du PC. Elle se connecte en scannant un QR code avec le téléphone, et partage tout le code du coffre avec l'app mobile.

Plateformes

Windows pour la plupart des inscrits, Linux pour les essais sur le poste de développement. Pas de macOS : il demande un Mac et un compte Apple payant.

02

La connexion par QR code

Tout existe déjà côté serveur (/api/auth/qr-session, plateformes windows et linux acceptées) et dans l'app mobile (Profil › Scanner un QR code › écran de confirmation). Aucun changement du serveur n'est nécessaire.

  1. L'ordinateur demande une session : POST /api/auth/qr-session avec le nom de l'ordinateur et sa plateforme. Il reçoit un identifiant, un jeton de suivi et le contenu du QR code, valable quelques minutes.

  2. Il affiche le QR code avec l'explication : « Ouvrez Alanya sur votre téléphone, Profil › Scanner un QR code ». Un QR expiré se renouvelle tout seul.

  3. Le téléphone scanne et l'inscrit approuve sur l'écran de confirmation qui existe déjà (nom et type de l'ordinateur).

  4. L'ordinateur reçoit ses jetons en interrogeant la session toutes les deux secondes. Ils sont rangés dans le coffre de mots de passe du système (Gestionnaire d'identifiants de Windows, trousseau libsecret sous Linux), jamais dans un fichier en clair.

  5. L'ordinateur apparaît dans « Appareils connectés » sur le téléphone, et s'y déconnecte comme les autres. Un ordinateur déconnecté reçoit un refus du serveur et revient à l'écran du QR code.

03

Les écrans

  • Une fenêtre, une barre à gauche : Accueil (espace utilisé, état des envois et de la sauvegarde du PC), Photos, Vidéos, Audio, Documents, Albums, Partager, Corbeille, Transferts, Réglages.
  • Au centre, le dossier : photos et vidéos en grille par jour, les autres en liste, avec les mêmes filtres que le téléphone (type, dossier d'origine, « Avec commentaire »).
  • Glisser-déposer depuis l'explorateur de fichiers vers un dossier ; un bouton « Ajouter » ouvre aussi le sélecteur du système.
  • Clavier et souris : double-clic pour ouvrir, Ctrl ou Maj + clic pour sélectionner, Ctrl+A, Suppr vers la corbeille, F2 pour renommer, clic droit pour le menu d'un fichier ou d'un dossier.
  • La visionneuse occupe la fenêtre : flèches gauche et droite, molette pour zoomer, Échap pour sortir, commentaire en bas.
  • Les transferts en bas de la fenêtre pendant un envoi ou un téléchargement : débit, pause, annuler.
  • Les textes reprennent ceux de l'app mobile, en français, anglais et chinois ; « SafeBox » en anglais.
04

Ajouter et télécharger

  • Le même chemin que le téléphone : réservation de la place, chiffrement SBX1 sur l'ordinateur, envoi direct chez MEGA, trois blocs à la fois, pause et reprise, fin vérifiée par le serveur. C'est le code du paquet commun, pas une copie.
  • En Original seulement dans cette version : la compression vidéo du téléphone passe par Android. Une photo, un audio ou un document part tel quel.
  • Un dossier déposé dans Albums devient un album, avec ses sous-dossiers ; déposé dans Photos ou Vidéos, ses fichiers y partent, triés par type, et son nom devient leur dossier d'origine (filtre).
  • Pas de doublon avec le téléphone : l'empreinte de l'original (SBF1) est la même partout. Une photo déjà sauvegardée depuis le téléphone est reconnue et n'est pas renvoyée.
  • Aperçus : pour une photo, une image de 480 px faite sur l'ordinateur et chiffrée, comme sur le téléphone. Pour une vidéo ou un PDF déposés depuis le PC, une icône dans cette version.
  • Télécharger : l'inscrit choisit un dossier du PC ; un dossier du coffre y est recréé avec ses sous-dossiers. Le déchiffrement se fait sur l'ordinateur.
05

Regarder et ranger

  • Vidéos et audios : lus par media_kit (libmpv), qui fonctionne sous Windows et Linux ; video_player, utilisé sur le téléphone, ne fonctionne pas sur ordinateur. Sous Windows, la bibliothèque est fournie avec l'application ; sous Linux, le paquet .deb la demande au système.
  • Commentaires : lire, écrire et enregistrer un audio au micro de l'ordinateur ; un seul commentaire par photo, comme sur le téléphone.
  • Ranger : toutes les actions du téléphone, avec les mêmes routes du serveur : dossiers et albums, déplacer, « ici ou partout », corbeille et restauration, libérer de l'espace.
06

Sauvegarder un dossier du PC

  1. L'inscrit choisit un ou plusieurs dossiers du PC (Images, Documents…), et pour chacun ce qui part : photos, vidéos, audios, documents.

  2. Un premier passage compare tout le dossier au coffre par les empreintes ; ce qui y est déjà ne repart pas. L'estimation et l'espace libre s'affichent avant de commencer, comme sur le téléphone.

  3. Ensuite, au fil de l'eau : un nouveau fichier ou un fichier modifié part tout seul. Sous Linux, la surveillance des sous-dossiers n'est pas fiable : un passage complet toutes les 15 minutes la complète.

  4. Un seul sens : un fichier supprimé du PC reste dans le coffre ; un fichier supprimé du coffre n'est plus sauvegardé (même règle que le téléphone, « ne plus sauvegarder »).

  5. Rangement : chaque fichier va dans le dossier de son type (Photos, Vidéos, Audio, Documents), avec le nom du dossier du PC comme dossier d'origine. Les plus récents d'abord ; quand l'espace manque, les plus anciens attendent.

Dans cette version, la sauvegarde tourne quand l'application est ouverte. Le lancement au démarrage de l'ordinateur et l'icône près de l'horloge viendront ensuite.

07

Le code

Tout dans le dépôt de l'app mobile (Alanya2026/Alanya), pour que les deux applications avancent ensemble :

DossierContenu
packages/alanya_safeboxLe paquet commun : chiffrement SBX1, modèles, règles de format, estimations, empreintes, API du coffre, gestionnaires d'envois et de téléchargements, cache des aperçus. Sans écran.
lib/ (app mobile)Inchangée pour l'inscrit : elle importe le paquet au lieu de ses propres fichiers. Restent chez elle ce qui touche au téléphone : discussions, compression Android, galerie, tâche de fond.
desktop/L'application de bureau, Windows et Linux : connexion, écrans, sauvegarde du PC, lecteur vidéo.
  • L'API du coffre ne dépend plus du client de l'app mobile : le paquet définit une petite interface HTTP (requêtes avec le jeton, renouvellement du jeton) que chaque application fournit.
  • La sortie du paquet ne change rien pour l'app mobile : ses 160 tests du coffre doivent passer avant et après, à l'identique.
  • Stockage local : jetons dans le coffre du système (flutter_secure_storage, Windows et Linux), réglages dans shared_preferences, fichiers dans le dossier de l'application.
08

Sécurité

  • Mêmes règles que le téléphone : le serveur remet la clé d'un fichier à son propriétaire connecté ; MEGA ne voit que des blocs chiffrés.
  • Les fichiers ne sont déchiffrés sur l'ordinateur qu'à la demande (visionneuse, téléchargement). Les aperçus restent chiffrés sur le disque.
  • « Se déconnecter » efface les jetons et tout ce que l'application a gardé sur l'ordinateur. Une déconnexion depuis le téléphone fait de même au prochain appel.
  • Un ordinateur partagé est le risque principal : l'écran de connexion le rappelle, et « Appareils connectés » sur le téléphone permet de couper l'accès à distance.

Ce que fait un inscrit, sous Windows

  1. Il ouvre la page de téléchargement et clique « Télécharger pour Windows » : AlanyaCoffre-Setup-1.0.0.exe.

  2. Il lance le fichier. Windows affiche « Windows a protégé votre ordinateur » (installateur non signé) : Informations complémentaires › Exécuter quand même. La page l'explique avec une capture.

  3. L'installateur ajoute « Alanya Coffre-fort » au menu Démarrer (raccourci sur le bureau au choix). Désinstallation par les Paramètres de Windows.

  4. Il ouvre l'application et scanne le code QR avec Alanya sur son téléphone (Compte et sécurité › Lier un nouvel appareil).

Ce que fait un inscrit, sous Linux

  1. Ubuntu, Debian, Mint : il télécharge alanya-coffre_1.0.0_amd64.deb et l'ouvre d'un double-clic ; la logithèque l'installe, l'application apparaît dans le menu.

  2. Autres distributions : il télécharge AlanyaCoffre-1.0.0.AppImage, autorise son exécution (clic droit › Propriétés) et l'ouvre. Rien à installer.

  3. Il scanne le code QR avec son téléphone, comme sous Windows.

Ce que nous faisons à chaque version

  1. Construire : GitHub Actions construit l'installateur Windows (Inno Setup), le .deb et l'AppImage (machine Ubuntu) à partir d'une étiquette de version.

    Le fichier de workflow touche .github/workflows : le jeton GitHub a le droit nécessaire.

  2. Essayer l'installateur sur un PC Windows et le .deb sur une Ubuntu propre (connexion QR, parcours, téléchargement).

  3. Publier : déposer les trois fichiers sur le VPS, mettre à jour la page de téléchargement et le fichier de version (version.json : numéro, adresses, notes).

  4. Prévenir : au démarrage, l'application lit version.json et affiche « Nouvelle version disponible » avec le lien ; l'inscrit réinstalle par-dessus, sans perdre sa connexion. Pas de mise à jour automatique en version 1.

Pour le faire connaître : un lien « Coffre-fort sur ordinateur » dans les réglages du coffre de l'application mobile, vers la page de téléchargement.

Limites et pistes

Seuls les PC 64 bits classiques (x64) ; les PC à puce ARM plus tard. L'avertissement de Windows ne disparaît qu'avec un certificat de signature (payant, pas prévu) ou par le Microsoft Store (inscription des développeurs individuels gratuite, à vérifier ; validation de Microsoft à chaque version). Côté Linux, Snap Store ou Flathub plus tard (gratuits).

Poste de développement Linux

Outils installés le 10/11 (pkg-config clang cmake ninja-build libgtk-3-dev libsecret-1-dev libmpv-dev). Lancer pour essayer : flutter run -d linux dans desktop/, ou flutter build linux --release puis build/linux/x64/release/bundle/alanya_coffre.
